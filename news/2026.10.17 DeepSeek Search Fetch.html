BÚSQUEDA PARA AGENTES

DeepSeek abre API de búsqueda y lectura web para crear asistentes que consulten fuentes actuales

La novedad acompaña la actualización Flash 1017 y permite a desarrolladores localizar páginas y recuperar su contenido; cobra por solicitud exitosa.

Un asistente puede redactar con soltura y, aun así, responder con información vieja si no consulta la web. Junto con la actualización V4.1-Flash-1017, DeepSeek abrió el 17 de octubre dos interfaces para desarrolladores: Search, que localiza páginas, y Fetch, que recupera el texto de una página como Markdown. La noticia compartida posteriormente por Investing.com reúne ambos cambios.

La versión del modelo ya se trató en IA Expo por sus demostraciones de juegos y escenas 3D. El ángulo nuevo de estas interfaces es más cotidiano para organizaciones: un asistente propio podría encontrar una convocatoria pública reciente, leer la página original y entregar un resumen con enlace para que una persona compruebe fechas y requisitos. Eso no equivale a que cada respuesta del chat público de DeepSeek use automáticamente estas API.

Según la documentación, Search devuelve resultados estructurados para una consulta y Fetch recupera una URL específica. Ambas requieren una clave de la API de DeepSeek y se llaman desde software propio. Fetch está sujeto a la disponibilidad y políticas de acceso del sitio consultado; la búsqueda también puede regresar sin resultados. Por eso sigue siendo necesario revisar la fuente original antes de actuar sobre una respuesta.

Cómo empezar si desarrollas un asistente

  1. Consulta la guía oficial y crea una clave en la plataforma de DeepSeek.
  2. Envía una consulta de prueba al punto de acceso Search y guarda título, URL y fecha de los resultados que devuelva.
  3. Pasa una URL seleccionada a Fetch para obtener el texto de la página, si el sitio permite el acceso.
  4. Haz que tu aplicación muestre el enlace y permita revisar manualmente la fecha y el contenido antes de usar el resumen.

Cada interfaz cuesta USD $0.75 por 1,000 solicitudes exitosas con resultado, según DeepSeek. Los llamados de Search y Fetch hechos como herramientas del servidor desde DeepSeek Harness, Claude Code o Codex son gratuitos temporalmente para usuarios de la API; el cobro de esos llamados empieza el 31 de octubre de 2026 a las 16:00 UTC. La tarifa del modelo, si se usa, es aparte.

Análisis

Por qué importa para la comunidad IAx

Para un pequeño equipo, estas interfaces pueden hacer más fácil que un asistente cite documentos actuales en lugar de depender solo de su entrenamiento. El beneficio dependerá de la calidad de las páginas recuperadas y de que el sistema conserve enlaces y fechas visibles.

En IA Expo Internacional vemos una oportunidad práctica en construir flujos modestos: buscar, leer una fuente y pedir confirmación humana. La web cambia y las páginas pueden fallar; por eso el diseño del asistente debe reconocer incertidumbre y dejar rastro de lo que consultó.
