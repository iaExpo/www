Un desarrollador afirma que Claude Code detectó un minero oculto mientras construía una app para su Mac

El relato procede de Reddit y fue recogido por medios el 19 y 20 de octubre; no hay análisis forense independiente del caso.

Captura del testimonio de Reddit reproducida por Gadget Review/Yahoo; documenta lo que afirma el usuario, no verifica por sí sola la infección. Procedencia de la imagen.

Preparado para IA Expo: 21 de octubre de 2026

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 2 min

 

Una computadora que se calienta demasiado puede tener una explicación sencilla, o un proceso inesperado consumiendo recursos. Un usuario de Reddit contó que, mientras Claude Code le ayudaba a construir una aplicación para vigilar la temperatura de su Mac, el asistente señaló un supuesto minero de criptomonedas.

El usuario afirmó que un proceso XMRig consumía alrededor de 1,175% de CPU y que el equipo alcanzó 112 °C. Gadget Review retomó el relato y Yahoo lo publicó el 20 de octubre. La captura disponible muestra lo que el usuario dice que ocurrió; no permite verificar de forma independiente cómo llegó el programa al equipo ni si la limpieza fue completa.

La enseñanza práctica es investigar síntomas con evidencia, no delegar a ciegas la reparación. Un asistente puede ayudar a interpretar una lista de procesos y archivos de inicio, pero también puede equivocarse o recomendar cambios peligrosos. Ante una posible infección conviene conservar registros, revisar la procedencia del software y recurrir a herramientas de seguridad confiables o a un especialista.

Cómo conocerlo o probarlo

  1. Si tu Mac se calienta sin motivo claro, abre Monitor de Actividad y ordena los procesos por uso de CPU.
  2. Anota el nombre y la ruta de cualquier proceso desconocido y contrástalos con documentación fiable; no elimines archivos del sistema solo por una sugerencia de IA.
  3. Si sospechas malware, desconecta tareas sensibles, actualiza el sistema y pide una revisión especializada antes de dar el equipo por limpio.

Por qué importa para la comunidad IAx

El episodio muestra una posibilidad útil de los asistentes de programación: detectar anomalías durante otra tarea. Pero el caso sigue siendo una experiencia individual, no una prueba de que Claude Code sea un antivirus.

En IA Expo Internacional recomendamos usar la IA como apoyo para formular hipótesis y traducir señales técnicas, mientras la confirmación y las acciones de limpieza quedan respaldadas por evidencia y criterio profesional.
