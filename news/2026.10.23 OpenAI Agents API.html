Agentes programados

La Agents API de OpenAI ya permite ejecutar agentes con horarios definidos

Los desarrolladores pueden iniciar una sesión nueva o continuar otra mediante una programación única o recurrente.

Imagen: OpenAI, ilustración de la Agents API publicada en septiembre; no muestra la función de horarios.

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 3 min

 

OpenAI anunció el 23 de octubre de 2026 las automatizaciones programadas para su Agents API. Una aplicación puede definir una hora concreta o una recurrencia para que un agente empiece una sesión nueva o retome una sesión anterior, sin requerir que una persona pulse un botón cada vez.

La documentación incluye la creación de horarios, la consulta de invocaciones y el seguimiento de su estado. Un caso práctico es pedir a un agente que revise cada dos horas la disponibilidad de reservaciones y avise cuando encuentre un espacio adecuado. La programación organiza el disparo; cada acción del agente todavía necesita los permisos y controles que correspondan a la aplicación.

Para probarlo, un equipo de desarrollo necesita acceso a la API: 1) configurar un agente y sus herramientas; 2) crear una automatización con una expresión de horario o una ejecución única; 3) decidir si cada activación abre una sesión o continúa una existente; 4) consultar el estado y los resultados de las invocaciones. La guía oficial incluye los parámetros exactos y ejemplos de código.

La función pertenece a la API para desarrolladores y no implica que esté disponible como botón equivalente en la interfaz de ChatGPT. OpenAI describió la Agents API como beta pública; el consumo de modelos y herramientas se cobra según sus tarifas aplicables, sin una cuota adicional de orquestación anunciada.

Análisis

Por qué importa para la comunidad IAx

Programar agentes acerca la automatización a procesos reales como revisión de inventarios, seguimiento de solicitudes o resúmenes periódicos. Para que sea útil, el equipo debe definir qué datos puede consultar el agente, cuándo debe detenerse y qué cambios requieren revisión humana.

En IA Expo Internacional recomendamos empezar con tareas de lectura y avisos medibles. Después se pueden incorporar acciones más sensibles cuando existan registros, límites y responsables claros.
