Qwen Code permite iniciar sesión con una suscripción Plus o Pro

El cambio evita configurar una clave API por separado para usar los modelos incluidos en la suscripción.

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 3 min

 

Un desarrollador que ya paga Qwen podía encontrarse con un trámite adicional para usar sus modelos en una herramienta de programación. La actualización semanal del 12 de noviembre añadió el inicio de sesión con la suscripción Plus o Pro en Qwen Code.

La misma cuenta puede usarse en terminal, VS Code y aplicación de escritorio. El cliente carga los modelos cubiertos por el plan y permite usar la búsqueda web integrada. Qwen indica que el consumo se imputa a la suscripción, sujeto a sus límites.

Para empezar, abra Qwen Code en terminal, escriba /auth, elija Qwen Account with Subscription y complete la autorización en el navegador. Después revise los modelos que aparecen en la cuenta y pruebe una tarea pequeña, como explicar una función o proponer una prueba.

La función exige una suscripción Qwen Plus o Pro vigente. La actualización también incorpora canales de WeChat, QQ y correo en Web Shell, más filtros para eventos de GitHub; su configuración requiere conexiones y permisos adicionales.
