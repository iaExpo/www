GitHub incorpora Gemini 4 Hydrogen como opción para programar con Copilot

El modelo ya figura como disponible en planes de pago, aunque su aparición en cada cuenta será gradual.

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 3 min

 

Cuando un equipo programa con un asistente, elegir el modelo puede influir en la rapidez y en la forma de resolver una tarea. GitHub anunció el 13 de noviembre que Gemini 4 Hydrogen ya está disponible como opción en GitHub Copilot.

GitHub lo presenta como un modelo orientado a programación con agentes, uso de herramientas y trabajos de varios pasos. Su disponibilidad cubre VS Code, Visual Studio, Copilot CLI, GitHub.com, la aplicación de Copilot y otras plataformas compatibles. Es una opción nueva dentro del producto, no un cambio automático para todos los proyectos.

Para probarlo, abra Copilot en una plataforma compatible, despliegue el selector de modelos y elija Gemini 4 Hydrogen. Puede pedirle, por ejemplo, que proponga una corrección y después revisar las pruebas y el cambio de código antes de aceptarlo.

Se requiere Copilot Pro, Pro+, Max, Business o Enterprise. El despliegue será gradual; los administradores de Business y Enterprise pueden desactivar el acceso mediante la política de modelos. GitHub indica facturación según el precio de lista del proveedor bajo el esquema de consumo.

Análisis

Por qué importa para la comunidad IAx

La variedad de modelos permite comparar resultados en tareas concretas, pero ninguna elección sustituye la revisión del código y de sus pruebas.

En IA Expo Internacional recomendamos evaluar una tarea real con criterios de calidad y costo antes de adoptar un modelo para todo el equipo.
