Genie 4 llega a la API para que desarrolladores creen experiencias dentro de mundos interactivos

La nueva vía permite experimentar en AI Studio y conectar mundos generados por IA con aplicaciones propias.

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 3 min

 

Un equipo que diseña una experiencia interactiva suele necesitar prototipos antes de construir un juego o una simulación. El 19 de noviembre Google abrió Genie 4 a desarrolladores mediante la Gemini API, un día después de anunciar el acceso a Project Genie para usuarios elegibles.

A partir de una descripción, una imagen de referencia o ambas, el modelo genera un mundo navegable con audio. Google describe controles de teclado y cambios mediante instrucciones en vivo, como modificar iluminación, clima u objetos. La empresa plantea usos de prototipos creativos, visualización espacial y pruebas para robótica.

Para explorarlo, abra Google AI Studio y busque el lienzo interactivo o las aplicaciones de ejemplo de Genie 4. Si desarrollará una integración, consulte la documentación de Gemini API para Interactions API y revise el precio antes de enviar solicitudes. El acceso de API y sus costos son distintos de la experiencia Project Genie anunciada el 18 de noviembre.

Es una herramienta de experimentación para desarrolladores; el anuncio no demuestra que los mundos generados sean aptos, sin trabajo adicional, para un videojuego terminado. Google señala que las salidas incluyen una marca de agua SynthID imperceptible.

Por qué importa para la comunidad IAx

En IA Expo Internacional recomendamos evaluar la experiencia, los costos y las limitaciones técnicas con un prototipo pequeño antes de prometer un producto final.
