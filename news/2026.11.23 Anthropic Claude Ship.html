Claude Ship reúne revisión, corrección y aprobaciones de código bajo las reglas de cada equipo

La función llegó en beta el 23 de noviembre para organizaciones Team y Enterprise con repositorios GitHub.

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 3 min

 

Una solicitud de cambio de código puede quedar detenida entre revisiones, fallas de pruebas y aprobación. Anthropic presentó el 23 de noviembre Claude Ship: combina Code Review, ya disponible de forma general, con PR Steward y Claude Approvals, dos agentes nuevos en beta.

PR Steward intenta resolver fallas de integración, conflictos y comentarios; informa qué cambió y cómo revertirlo. Claude Approvals aplica una política escrita por el equipo y puede aprobar cambios rutinarios si esa política lo permite. No se trata de aprobación automática universal: permisos, reglas de rama y configuración del repositorio siguen vigentes.

Un desarrollador puede actualizar Claude Code y ejecutar /ship para preparar una solicitud de cambio. Administradores de planes Team o Enterprise pueden habilitarlo por repositorio GitHub, definir límites de gasto y comenzar con aprobaciones solo en modo de observación. El uso se factura por tokens; la beta no está disponible para organizaciones con retención cero, configuración HIPAA o claves de cifrado administradas por el cliente.

Por qué importa para la comunidad IAx

La utilidad para equipos depende de políticas legibles y revisión humana en los cambios de mayor riesgo. La automatización puede reducir esperas, pero Anthropic advierte que su revisión puede pasar por alto defectos.
