Perplexity permite consultar versiones históricas de la web desde sus API

Time Machine fija una fecha límite para buscar y leer páginas tal como estaban entonces; está dirigido a desarrolladores.

Por la redacción de IA Expo Internacional  |  Tiempo de lectura: 3 min

 

Una investigación sobre una decisión pasada puede contaminarse con noticias publicadas después. Perplexity lanzó el 25 de noviembre Time Machine para sus API Search y Context, que recupera copias guardadas de páginas hasta una fecha elegida, en vez de consultar su versión actual.

Un equipo puede usarlo para reconstruir qué información había antes de un anuncio empresarial o para evaluar si un agente habría respondido bien con las fuentes disponibles en ese momento. Para probarlo se necesita una clave de API: se agrega el parámetro snapshot_as_of, con fecha y hora, a una búsqueda o a la lectura de una URL. La misma fecha debe aplicarse a ambos pasos.

El historial disponible llega hasta 365 días atrás y crecerá con las capturas futuras. Perplexity advierte que hay límites de solicitudes por defecto. No hay recargo por el corte histórico: Search API cuesta USD $5 por 1,000 solicitudes y Context API USD $1 por 1,000 URL leídas. Es una función de API, no del buscador de uso general.
